EXERCICIO 2.1 — Tempo de espera                        [M]
------------------------------------------------------------
Quando uma senha e chamada, calcula e mostra quantos
minutos o cliente esperou.

O que fazer:
  1. Cria uma funcao que converte "HH:MM" para minutos:
       int para_minutos(string h) {
           int horas  = (h[0]-'0')*10 + (h[1]-'0');
           int mins   = (h[3]-'0')*10 + (h[4]-'0');
           return horas * 60 + mins;
       }

  2. Em chamar_proximo(), calcula a diferenca:
       int espera = para_minutos(hora_agora())
                  - para_minutos(hora_entrada[frente]);
       cout << "Tempo de espera: " << espera << " minutos\n";

  3. Grava tambem no log.


EXERCICIO 2.2 — Cancelar senha                         [M]
------------------------------------------------------------
Adiciona a opcao [7] Cancelar senha ao menu.

O que fazer:
  1. Adiciona um novo vector: bool cancelado[MAX]
     (inicializa tudo a false)

  2. Cria a funcao cancelar_senha():
       cabecalho();
       cout << "Numero da senha a cancelar: ";
       int num; cin >> num; cin.ignore();

       for (int i = frente; i < total; i++) {
           if (senhas[i] == num && !atendido[i]
                                && !cancelado[i]) {
               cancelado[i] = true;
               cout << "Senha " << num << " cancelada.\n";
               pausar(); return;
           }
       }
       cout << "Senha nao encontrada.\n";
       pausar();

  3. Actualiza ver_fila() e em_espera() para ignorar
     senhas com cancelado[i] == true.

  4. Actualiza chamar_proximo() para saltar canceladas:
       while (frente < total &&
              (atendido[frente] || cancelado[frente]))
           frente++;


EXERCICIO 2.3 — Pesquisar cliente                      [M]
------------------------------------------------------------
Adiciona a opcao [8] Pesquisar pelo nome.

O que fazer:
  1. Cria a funcao pesquisar():
       cabecalho();
       cout << "Nome a pesquisar: ";
       string termo; getline(cin, termo);

       bool encontrou = false;
       for (int i = 0; i < total; i++) {
           if (nomes[i].find(termo) != string::npos) {
               cout << "[" << senhas[i] << "] "
                    << nomes[i] << " - " << servico[i]
                    << " - "
                    << (atendido[i] ? "Atendido"
                                    : "Em espera")
                    << "\n";
               encontrou = true;
           }
       }
       if (!encontrou) cout << "Nenhum resultado.\n";
       pausar();

  Nota: string::npos e o valor retornado por find()
  quando nao encontra nada.

EXERCICIO 3.3 — Exportar relatorio                     [D]
------------------------------------------------------------
Adiciona opcao [9] que gera um ficheiro relatorio.html
com uma tabela de todos os atendimentos da sessao.

Estrutura do ficheiro gerado:
  <html>
  <body>
  <h1>Relatorio de Atendimentos</h1>
  <table border="1">
    <tr><th>Senha</th><th>Nome</th><th>Servico</th>
        <th>Hora entrada</th></tr>
    <tr><td>001</td><td>Ana</td>...</tr>
  </table>
  </body>
  </html>

Funcao a criar:
  void exportar_html() {
      ofstream f("relatorio.html");
      f << "<html><body>\n";
      f << "<h1>Relatorio</h1>\n";
      f << "<table border='1'>\n";
      f << "<tr><th>Senha</th><th>Nome</th>"
           "<th>Servico</th><th>Hora</th></tr>\n";
      for (int i = 0; i < total; i++) {
          if (atendido[i])
              f << "<tr><td>" << senhas[i] << "</td>"
                << "<td>" << nomes[i]     << "</td>"
                << "<td>" << servico[i]   << "</td>"
                << "<td>" << hora_entrada[i] << "</td>"
                << "</tr>\n";
      }
      f << "</table></body></html>\n";
      cout << "Relatorio gerado: relatorio.html\n";
  }
