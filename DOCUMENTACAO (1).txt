------------------------------------------------------------
  1. INTRODUCAO
------------------------------------------------------------

O Gestor de Filas de Espera e um programa de terminal que
simula um sistema real de gestao de senhas de atendimento,
como os usados em bancos, hospitais e reparticoes publicas.

O programa gere dois perfis de utilizador:

  - CLIENTE     : retira uma senha com nome e servico
  - FUNCIONARIO : chama a proxima senha da fila

Toda a interacao e feita via menu numerado no terminal,
com interface colorida usando codigos de escape ANSI.
Os atendimentos sao gravados num ficheiro de log diario.


------------------------------------------------------------
  2. FUNCIONALIDADES
------------------------------------------------------------

  [1] Retirar senha
      O cliente introduz o seu nome e escolhe um servico.
      O sistema emite uma senha com numero sequencial e
      hora de entrada, exibindo um bilhete visual colorido.

  [2] Chamar proximo
      O funcionario chama o primeiro cliente da fila
      (logica FIFO). O sistema exibe os dados do cliente,
      mostra quantos ainda aguardam e grava o atendimento
      no ficheiro atendimentos.txt com hora de saida.

  [3] Ver fila actual
      Lista em formato tabular todos os clientes ainda
      em espera. O proximo a ser chamado aparece destacado
      a verde com a indicacao "<< PROXIMO".

  [4] Historico da sessao
      Mostra todos os atendimentos ja concluidos durante
      a sessao actual: senha, nome, servico e hora.

  [5] Ver log em disco
      Le e exibe o conteudo completo do ficheiro
      atendimentos.txt, incluindo sessoes anteriores.

  [6] Estatisticas
      Exibe totais globais (emitidas, atendidas, em espera)
      e barras de progresso ASCII por servico, calculados
      em tempo real a partir do vector de senhas.

  [0] Sair
      Termina o programa com mensagem de despedida.


------------------------------------------------------------
  3. SERVICOS DISPONIVEIS
------------------------------------------------------------

  [1]  Tesouraria          (cor: amarelo brilhante)
  [2]  Secretaria          (cor: ciano brilhante)
  [3]  Recursos Humanos    (cor: magenta brilhante)
  [4]  Atendimento Geral   (cor: verde brilhante)


------------------------------------------------------------
  4. ARQUITECTURA DO CODIGO
------------------------------------------------------------

O codigo esta organizado em tres camadas com
responsabilidades bem definidas:

  CAMADA 1 — APRESENTACAO
    namespace Cor   : codigos ANSI centralizados
    class UI        : metodos static de desenho no ecra

  CAMADA 2 — LOGICA DE NEGOCIO
    class GestorFila : fila FIFO, log, estatisticas

  CAMADA 3 — DADOS
    class Senha      : registo de um cliente na fila

  PONTO DE ENTRADA
    main()           : instancia GestorFila, loop do menu


------------------------------------------------------------
  5. DESCRICAO DAS CLASSES
------------------------------------------------------------

  ── namespace Cor ────────────────────────────────────────

  Centraliza todos os codigos de escape ANSI do programa.
  Usa constexpr const char* para eficiencia em tempo de
  compilacao e funcoes inline para aliases semanticos.

  Constantes definidas:
    RST, B, DIM                   estilos de texto
    VERM, VERDE, AMAR, AZUL       cores de primeiro plano
    MAG, CIANO, BRANCO
    AMAR_B, CIANO_B, MAG_B        versoes brilhantes
    VERDE_B
    BG_AZUL, BG_MAG               cores de fundo

  Funcoes inline semanticas:
    titulo()    -> negrito + ciano
    destaque()  -> negrito + amarelo
    sucesso()   -> negrito + verde
    aviso()     -> negrito + vermelho
    info()      -> negrito + azul
    label()     -> dim + branco
    valor()     -> negrito + branco


  ── class UI ─────────────────────────────────────────────

  Responsavel pelo desenho do ecra. Todos os metodos sao
  static porque a classe nao guarda estado proprio.

  Metodos:
    linha_h(cor, char, n)
      Desenha uma linha horizontal colorida de n caracteres.
      Exemplo: linha_h(Cor::CIANO, '=', 52)

    cabecalho_seccao(tag, titulo, cor)
      Desenha um banner de seccao com duas linhas duplas
      e o titulo centrado entre elas.

    prop(label, valor, cor_val)
      Exibe um par label/valor com alinhamento fixo de
      12 caracteres para o label.

    barra_prog(valor, maximo, cor)
      Desenha uma barra de progresso ASCII de 20 posicoes.
      Exemplo: [########............] 4

    pausar()
      Exibe mensagem colorida e aguarda ENTER do utilizador.
      Usa cin.ignore com numeric_limits para seguranca.

    limpar_ecra()
      Executa "cls" no Windows ou "clear" no Unix.


  ── class Senha ──────────────────────────────────────────

  Representa o registo completo de um cliente na fila.

  Atributos:
    numero        int          numero sequencial da senha
    nome          std::string  nome do cliente
    servico       std::string  servico solicitado
    hora_entrada  std::string  hora de entrada (HH:MM)
    atendido      bool         false = aguarda, true = feito

  Construtores:
    Senha()
      Construtor padrao. Inicializa numero=0, atendido=false.

    Senha(num, nome, servico, hora)
      Construtor com parametros. Usado em retirar_senha().

  Metodos:
    num_str() const -> std::string
      Retorna o numero formatado com zeros a esquerda.
      Exemplo: senha 7 -> "007"


  ── class GestorFila ─────────────────────────────────────

  Nucleo do sistema. Encapsula toda a logica de negocio,
  a estrutura de dados FIFO e o acesso ao ficheiro de log.

  Atributos privados:
    senhas          std::vector<Senha>   fila dinamica
    frente          int                  indice FIFO actual
    contador        int                  proximo numero
    ficheiro_log    std::string          caminho do log

  Constantes publicas estaticas:
    NUM_SERVICOS    int = 4
    SERVICOS        std::array<string, 4>
    COR_SERV        std::array<string, 4>

  Metodos publicos:
    GestorFila(ficheiro_log)
      Construtor. Recebe o caminho do ficheiro de log.
      Valor padrao: "atendimentos.txt"

    total() const -> int
      Retorna o numero total de senhas emitidas na sessao.

    em_espera() const -> int
      Conta senhas com atendido == false.

    atendidos() const -> int
      Retorna total() - em_espera().

    retirar_senha()
      Valida espaco na fila. Le nome com getline e servico
      com cin. Cria Senha e adiciona ao vector com push_back.
      Exibe bilhete visual colorido.

    chamar_proximo()
      Avanca frente sobre senhas ja marcadas. Marca
      atendido = true. Exibe dados do cliente. Calcula
      quantos ainda aguardam. Chama gravar_log().
      Incrementa frente.

    mostrar_fila() const
      Itera o vector a partir de frente. Filtra atendido
      == false. Destaca o primeiro a verde.

    mostrar_historico() const
      Itera todo o vector. Filtra atendido == true.

    ver_log() const
      Abre ifstream. Le linha a linha com getline.

    mostrar_estatisticas() const
      Usa std::array<int,4> para contagens por servico.
      Calcula barras e exibe totais.

    imprimir_estado(data, hora) const
      Limpa o ecra e desenha o cabecalho com estado actual.

  Metodos privados:
    gravar_log(s) const
      Abre ofstream em modo append. Escreve linha formatada
      com data, senha, horas, nome e servico.

    hora_actual() -> std::string (static)
      Usa time() + strftime para retornar "HH:MM".

    data_actual() -> std::string (static)
      Usa time() + strftime para retornar "DD/MM/AAAA".

    cor_servico(nome) const -> std::string
      Percorre SERVICOS[]. Retorna COR_SERV[i] se encontrar.


------------------------------------------------------------
  6. LOGICA FIFO — FUNCIONAMENTO INTERNO
------------------------------------------------------------

A fila e implementada com um std::vector<Senha> e um
indice inteiro "frente" que avanca sem deslocar elementos.
Esta tecnica tem custo O(1) por operacao de chamada.

Evolucao do estado interno:

  Inicio:
    senhas = []      frente = 0    contador = 1

  Apos 4 retiradas:
    senhas = [S1, S2, S3, S4]
    frente = 0

  Apos 2 chamadas:
    senhas = [S1(ok), S2(ok), S3, S4]
                              ^
                           frente = 2

  Nova retirada:
    senhas = [S1(ok), S2(ok), S3, S4, S5]
                              ^
                           frente = 2

Passos de chamar_proximo():
  1. Enquanto senhas[frente].atendido == true, frente++
  2. Se frente >= total(): avisa fila vazia e retorna
  3. senhas[frente].atendido = true
  4. Exibe dados no ecra
  5. Conta senhas com atendido == false para apos frente
  6. Chama gravar_log(senhas[frente])
  7. frente++


------------------------------------------------------------
  7. FICHEIRO DE LOG
------------------------------------------------------------

Caminho:  atendimentos.txt  (mesmo directorio do executavel)
Modo:     append  (ios::app) — acumula entre sessoes

Formato de cada linha:
  [DD/MM/AAAA]  Senha: NNN  |  Entrada: HH:MM  |
  Saida: HH:MM  |  Cliente: NOME (40 chars)  |  Servico: X

Exemplo:
  [20/03/2026]  Senha: 001  |  Entrada: 13:45  |  Saida: 13:52  |  Cliente: Ana Silva                      |  Servico: Tesouraria
  [20/03/2026]  Senha: 002  |  Entrada: 13:46  |  Saida: 13:59  |  Cliente: Joao Moreira                   |  Servico: Secretaria

O ficheiro e criado automaticamente na primeira chamada.
Se nao existir, a opcao 5 informa o utilizador.


------------------------------------------------------------
  8. SISTEMA DE CORES ANSI
------------------------------------------------------------

Cores por contexto semantico:

  Ciano          Bordas, menus, cabeçalhos gerais
  Amarelo        Numeros de senha, opcoes do menu
  Verde          Sucesso, confirmacoes, fila vazia
  Vermelho       Avisos, erros, opcao Sair
  Magenta        Historico, banner de chamada de senha
  Azul           Fundo do cabecalho, bilhete de senha
  Dim/Branco     Labels e texto secundario

Cores por servico:

  Tesouraria        Amarelo brilhante   \033[93m
  Secretaria        Ciano brilhante     \033[96m
  Recursos Humanos  Magenta brilhante   \033[95m
  Atendimento Geral Verde brilhante     \033[92m

Activacao no Windows:
  A funcao ativar_ansi() e chamada no inicio do main().
  Invoca SetConsoleMode() com ENABLE_VIRTUAL_TERMINAL_PROCESSING
  e SetConsoleOutputCP(65001) para suporte UTF-8.
  Compilacao condicional: #ifdef _WIN32 / #else.

------------------------------------------------------------
  11. CONCEITOS C++17 PRATICADOS
------------------------------------------------------------

  Orientacao a Objectos
    - Encapsulamento com atributos privados
    - Construtores com e sem parametros
    - Metodos const para leitura segura
    - Separacao de responsabilidades entre classes
    - Metodos static em classe sem estado (UI)

  Estruturas de Dados
    - std::vector<Senha>    fila dinamica FIFO
    - std::array<T,N>       tabelas de tamanho fixo
    - Indice frente para avanco O(1) na fila

  Strings e Formatacao
    - std::string com operadores nativos (==, +, empty)
    - std::ostringstream para formatacao numerica
    - std::iomanip : setw, setfill, left, right

  I/O de Ficheiros
    - std::ofstream com ios::app para log persistente
    - std::ifstream com getline para leitura segura

  Organizacao de Codigo
    - namespace para isolar codigos ANSI
    - constexpr para constantes em tempo de compilacao
    - inline para funcoes de alias semantico
    - Compilacao condicional #ifdef _WIN32

  Entrada do Utilizador
    - cin com tratamento de falha (cin.clear)
    - cin.ignore com numeric_limits para limpar buffer
    - getline para ler nomes com espacos
